**HiveBoard**
HiveBoard is a real-time collaborative whiteboard application that allows users to create, share, and collaborate on digital canvases.
It features drawing tools, chat functionality, AI-powered assistance, meeting management, and user presence indicators, all built with modern web technologies.

**Features**
Real-time Collaboration: Draw, edit, and interact on shared canvases with multiple users simultaneously using WebSockets.
Drawing Tools: Comprehensive toolbar with various drawing tools, colors, and shapes.
Chat System: Integrated chat panel for communication during sessions.
AI Chat: AI-powered chat assistant for enhanced collaboration and idea generation.
Meeting Management: Create and join meetings with participant management.
Room System: Organize canvases into rooms for better project management.
User Authentication: Secure login with Google OAuth integration.
User Presence: See who is online and actively participating.
Responsive Design: Works seamlessly across desktop and mobile devices.
Export Functionality: Save and share your creations.

**Tech Stack**

**Frontend**
React - UI library
TypeScript - Type safety
Vite - Build tool and dev server
Tailwind CSS - Utility-first CSS framework
Shadcn/ui - Component library
Socket.io-client - Real-time communication
React Router - Client-side routing
Framer Motion - Animations

**Backend**
Node.js - Runtime environment
Express.js - Web framework
Socket.io - Real-time bidirectional communication
MongoDB - NoSQL database
Mongoose - ODM for MongoDB
Passport.js - Authentication middleware
Google OAuth 2.0 - Social authentication
JWT - Token-based authentication
Google Generative AI - AI integration

**DevOps**
Docker - Containerization
Docker Compose - Multi-container orchestration
GitHub Actions - CI/CD pipeline
